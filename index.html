How to Use in CapCut

  1. Edit your main video in CapCut (the way you normally do).
  2. Use Overlay → Add Overlay to place this caption video on the layer above.
  3. Select the caption video → Cutout → Chroma Key → pick the green color → raise the Intensity. The green disappears, only the captions remain. (If you exported with the Transparent background, skip this step completely.)
  4. If the timing is slightly off, slide the overlay a little forward/back.
